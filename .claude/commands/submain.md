[상황] 콘텐츠/우리웹진.md를 채웠고, 콘텐츠 폴더마다 /article로 상세페이지를 만들었다.
[할 일] 서브메인을 만들어줘.
[의도] 광고를 누르면 처음 도착하는 우리 웹진 첫 페이지를 만들려는 것이다.
[조건] CLAUDE.md 4번 '서브메인' 순서대로. 먼저 git pull --no-rebase. 첫 화면 사진 칸이 비어 있으면 대표 콘텐츠 폴더의 사진에서 골라 규칙/사진정리.md대로 tools/photo.py로 잘라 (채워져 있으면 그대로). 규칙/submain.md와 규칙/공통틀.md를 따르고 발췌 표시(data-excerpt)를 빠뜨리지 마. 카드 내용은 각 콘텐츠의 글.md에서 가져오고, 우리웹진.md와 글.md에 없는 문구는 쓰지 마. 모든 상세페이지의 공통 틀과 관련 기사도 맞춰 주고, public/css/style.css를 우리웹진.md 디자인 칸의 디자인 파일로 맞춰 줘 (규칙/디자인.md, 팀 조정 칸은 옮겨 붙이고, 바꿨으면 알려 줘). 콘텐츠 폴더에 없는 public/ 파일은 지우고 알려줘. 다른 언어가 있으면 규칙/언어.md대로 번역 파일을 모두 맞추고 그 언어의 서브메인 · 상세페이지도 맞춰 줘 (다른 언어 칸에서 뺀 언어의 폴더는 지운다).
