# 공통 틀 규칙 (Claude Code가 읽는다)

같은 팀의 **서브메인과 모든 상세페이지**(블로그형·매거진 커버형·리스트형·코스형·풀페이지형·카드뉴스형)는 머리와 바닥이 **똑같다.** 기사 유형이 달라도 독자는 같은 웹진 안에 있다고 느껴야 하기 때문이다.

- 학생은 이 파일을 고치지 않는다. `{ }` 자리는 `콘텐츠/우리웹진.md`의 웹진 이름 · 한 줄 소개 · 메뉴 카테고리로 채운다
- 웹진메인(한경닷컴이 따로 만드는 한 페이지)은 이 규칙을 따르지 않는다

## 0. 고정 영역과 콘텐츠 영역
- **고정 영역** = 상단 바 · 헤더 · 메뉴(GNB) · 푸터. 페이지가 바뀌어도, PC든 휴대폰이든 같은 구성 · 같은 글자다
- **콘텐츠 영역** = 그 사이(히어로, 카드, 본문). 페이지마다, 화면 폭마다 바뀐다
- PC용 · 모바일용 레이아웃을 따로 그리거나 만들어도 고정 영역은 그대로 복사해 쓴다. 휴대폰에서 메뉴를 ☰(햄버거)로 숨기거나 항목을 빼지 않는다. 글자 크기만 모바일 규칙대로 줄이고, 넘치면 줄을 바꾼다

## 1. 공통 틀 = 세 부분

| 부분 | 내용 | 누가 정하나 |
|---|---|---|
| 상단 바 | "한경 웹진 메인으로" 링크 (다른 언어가 있으면 오른쪽에 언어 전환, 6번) | 한경닷컴 (모든 팀 같음, 수정 금지) |
| 헤더 + 메뉴(GNB) | 웹진 이름 · 한 줄 소개 · 카테고리 메뉴 | 팀 (팀 안의 모든 페이지 같음) |
| 푸터 | 웹진 이름 · 개인정보처리방침 | 팀 (팀 안의 모든 페이지 같음) |

## 2. 코드 (그대로 복사한다)

서브메인(`public/index.html`)과 상세페이지(`public/articles/…html`)는 폴더 깊이만 다르다. **경로 앞부분(`./`, `../`)만 바꾸고 나머지는 글자 하나까지 같게 쓴다.**

### 서브메인 `public/index.html`
```html
<div class="topbar"><div class="container"><a href="../index.html">한경 웹진 메인으로</a></div></div>
<header class="wz-header"><div class="container"><a class="wz-name" href="./index.html">{웹진 이름}</a><span class="wz-tagline">{한 줄 소개}</span><nav class="wz-nav" aria-label="카테고리"><a href="./index.html#cat-1">{카테고리1}</a><a href="./index.html#cat-2">{카테고리2}</a><a href="./index.html#cat-3">{카테고리3}</a></nav></div></header>
```
```html
<footer class="site-footer"><div class="container"><span>{웹진 이름} · 한경 웹진</span><a href="#">개인정보처리방침</a></div></footer>
```

### 상세페이지 `public/articles/페이지이름.html`
```html
<div class="topbar"><div class="container"><a href="../../index.html">한경 웹진 메인으로</a></div></div>
<header class="wz-header"><div class="container"><a class="wz-name" href="../index.html">{웹진 이름}</a><span class="wz-tagline">{한 줄 소개}</span><nav class="wz-nav" aria-label="카테고리"><a href="../index.html#cat-1">{카테고리1}</a><a href="../index.html#cat-2">{카테고리2}</a><a href="../index.html#cat-3">{카테고리3}</a></nav></div></header>
```
푸터는 서브메인과 같다.

메뉴의 `<a>`는 메뉴 카테고리 수만큼 쓴다 (위 코드는 3개일 때).

## 3. 메뉴(GNB)
- 항목 = `우리웹진.md`의 메뉴 카테고리, 적힌 순서대로 `cat-1`, `cat-2` … (카테고리가 2개면 2개, 4개면 4개)
- 누르면 서브메인의 그 카테고리 첫 카드로 간다. 서브메인에서 각 카테고리의 **첫 카드**(위에서부터 처음 나오는 카드, 대표 기사 포함)에 `id="cat-N"`을 붙인다
- 서브메인이 아직 없을 때도 메뉴는 메뉴 카테고리를 모두 넣는다. 그래야 페이지를 만들 때마다 메뉴가 바뀌지 않는다
- `/submain` 때 콘텐츠가 하나도 없는 카테고리가 있으면 알려준다. 지우는 것은 학생이 `우리웹진.md`에서 하고, 그 뒤 `/submain`으로 모든 페이지의 메뉴를 한꺼번에 고친다
- 메뉴 모양: 15px / 500, 항목 사이 16px, 가운데 정렬. 휴대폰에서도 한 줄로 두고, 넘치면 항목째 다음 줄로 넘긴다 (항목 글자 중간에서 끊지 않는다)

## 4. 지키는 것
- 헤더를 사진 위에 겹쳐 올리지 않는다. **풀페이지형·매거진 커버형도 헤더 아래에서 시작한다**
- 풀페이지형처럼 배경이 어두운 페이지에서도 상단 바·헤더·푸터의 색은 다른 페이지와 같다
- 헤더와 푸터의 모양(색·글자 크기)은 `public/css/style.css`의 `.topbar`, `.wz-header`, `.wz-nav`, `.site-footer`에서만 정한다. **다섯 디자인 파일(`규칙/디자인.md`) 모두 같은 값**이라 디자인을 바꿔도 공통 틀 모양은 그대로다. 페이지마다 따로 꾸미지 않고, 팀 조정 칸에서도 고치지 않는다
- 시안(Claude Design 등)을 보고 만들 때도 공통 틀의 배치는 바꾸지 않는다. 바꾸려면 강사와 상의하고, 바꾸면 모든 페이지를 한꺼번에 바꾼다

## 5. 검수
모든 페이지에서 상단 바·헤더·푸터를 꺼내, 경로 앞부분(`../`)을 맞춘 뒤 **글자 하나까지 같은지** 비교한다. 다른 언어가 있으면 같은 언어끼리 비교하고, 언어 전환 링크(페이지마다 다르다)는 빼고 비교한다. 다르면 검수 결과에 페이지 이름과 다른 곳을 적는다.

## 6. 다른 언어가 있을 때 (규칙/언어.md)
`우리웹진.md`의 다른 언어 칸에 `en` 등이 있으면 **모든 언어의 모든 페이지** 상단 바 오른쪽에 언어 전환을 넣는다. 다른 언어 칸이 비어 있으면 넣지 않는다 (위 2번 그대로).

- 링크는 **지금 페이지와 같은 페이지의 그 언어 판**으로 간다 (영어 상세페이지의 `한국어` → 같은 기사의 한국어 페이지)
- 지금 보고 있는 언어에 `aria-current="page"`를 붙인다 (굵게 보인다)
- 언어 이름(`한국어`, `English`, `日本語`, `中文`)은 어느 언어 페이지에서나 그 언어로 쓴다. `aria-label`과 상단 바 · 메뉴 · 푸터 글자는 그 페이지 언어로 쓴다 (규칙/언어.md 6번 표)

### 한국어 서브메인 `public/index.html`
```html
<div class="topbar"><div class="container"><a href="../index.html">한경 웹진 메인으로</a><nav class="lang-switch" aria-label="언어"><a href="./index.html" lang="ko" hreflang="ko" aria-current="page">한국어</a><a href="./en/index.html" lang="en" hreflang="en">English</a></nav></div></div>
```
### 한국어 상세페이지 `public/articles/페이지이름.html`
```html
<div class="topbar"><div class="container"><a href="../../index.html">한경 웹진 메인으로</a><nav class="lang-switch" aria-label="언어"><a href="../articles/페이지이름.html" lang="ko" hreflang="ko" aria-current="page">한국어</a><a href="../en/articles/페이지이름.html" lang="en" hreflang="en">English</a></nav></div></div>
```
### 영어 서브메인 `public/en/index.html`
```html
<div class="topbar"><div class="container"><a href="../../index.html">Hankyung Webzine home</a><nav class="lang-switch" aria-label="Language"><a href="../index.html" lang="ko" hreflang="ko">한국어</a><a href="../en/index.html" lang="en" hreflang="en" aria-current="page">English</a></nav></div></div>
<header class="wz-header"><div class="container"><a class="wz-name" href="./index.html">{웹진 이름 번역}</a><span class="wz-tagline">{한 줄 소개 번역}</span><nav class="wz-nav" aria-label="Categories"><a href="./index.html#cat-1">{카테고리1 번역}</a>…</nav></div></header>
```
```html
<footer class="site-footer"><div class="container"><span>{웹진 이름 번역} · Hankyung Webzine</span><a href="#">Privacy policy</a></div></footer>
```
### 영어 상세페이지 `public/en/articles/페이지이름.html`
```html
<div class="topbar"><div class="container"><a href="../../../index.html">Hankyung Webzine home</a><nav class="lang-switch" aria-label="Language"><a href="../../articles/페이지이름.html" lang="ko" hreflang="ko">한국어</a><a href="../../en/articles/페이지이름.html" lang="en" hreflang="en" aria-current="page">English</a></nav></div></div>
```
헤더 · 푸터는 영어 서브메인과 같고 경로만 `../index.html`이다.

- 언어 전환의 링크 순서는 한국어, 그다음 다른 언어 칸에 적힌 순서다
- 모양은 `public/css/style.css`의 `.lang-switch`에서만 정한다 (왼쪽 한경 웹진 메인 링크, 오른쪽 언어 전환. 휴대폰도 같다)

## 7. 팀 GTM 코드 (측정)

모든 페이지(서브메인 · 상세페이지 · 다른 언어 페이지)에 같은 코드를 넣는다. 아이디는 `콘텐츠/우리웹진.md` 측정 칸의 `팀 GTM 아이디`다.

- 아이디가 비어 있으면 `<head>`의 `<!-- 팀 GTM 코드 자리 -->` 주석만 둔다
- 아이디가 있으면 `<!-- 팀 GTM 코드 자리 -->` 바로 아래에 head 조각을, `<body>` 바로 뒤에 noscript 조각을 넣는다. `GTM-XXXXXXX`만 팀 아이디로 바꾸고 나머지는 글자 하나까지 그대로 쓴다
- 두 조각은 구글이 정한 코드라 바깥 주소(googletagmanager.com)와 `style`이 들어 있어도 된다 (CLAUDE.md 2번 1 · 규칙/디자인.md 5번의 예외)
- 한경 측정 코드(GA4) 자리는 한경닷컴이 채운다. 팀 GTM 코드와 섞지 않고 지우지 않는다
- GA4 · 메타 픽셀 · 틱톡 픽셀 같은 태그는 GTM 안에서 켠다 (측정 교안). 페이지에 따로 넣지 않는다

head 조각 (`<!-- 팀 GTM 코드 자리 -->` 바로 아래):
```html
<!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-XXXXXXX');</script>
<!-- End Google Tag Manager -->
```

body 조각 (`<body>` 바로 뒤):
```html
<!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-XXXXXXX"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->
```
