# 디자인 규칙 (Claude Code가 읽는다)

웹진의 모양(색 · 글꼴 · 크기 · 모서리 · 배치)은 **디자인 파일 하나**가 정한다. 팀은 `콘텐츠/우리웹진.md`의 디자인 칸에 다섯 가지 중 하나의 글자(A~E)를 쓴다. 비워 두면 C다.

- 학생은 이 파일과 `규칙/디자인/` 안의 파일을 고치지 않는다
- 다섯 디자인은 **같은 HTML**을 쓴다. 디자인을 바꾸면 `public/css/style.css`만 바뀌고 html은 그대로다
- 공통 틀(상단 바 · 헤더 · 메뉴 · 푸터)은 다섯 디자인 모두 같은 모양이다 (`규칙/공통틀.md`)

## 1. 다섯 가지 디자인

| 칸에 쓰는 글자 | 이름 | 느낌 | 어울리는 웹진 | 파일 |
|---|---|---|---|---|
| `A` | 에디토리얼 | 흰 바탕, 명조 제목, 신문 · 잡지 지면 | 글과 이야기가 중심 | `규칙/디자인/A.css` |
| `B` | 모던 클린 | 둥근 카드와 사진, 청록 포인트 | 코스 · 정보가 중심 | `규칙/디자인/B.css` |
| `C` | 풀블리드 | 사진을 화면 가득, 진한 남색과 노랑 | 좋은 가로 사진이 많다 | `규칙/디자인/C.css` |
| `D` | 미니멀 매거진 | 밝은 웜그레이 바탕, 가는 선, 올리브 포인트 | 카페 · 공방 · 사람 이야기 | `규칙/디자인/D.css` |
| `E` | 볼드 그래픽 | 귤색 블록, 아주 큰 글씨, 굵은 검정 테두리 | 액티비티 · 젊은 독자 | `규칙/디자인/E.css` |

## 2. 디자인마다 다른 곳

| | A 에디토리얼 | B 모던 클린 | C 풀블리드 | D 미니멀 매거진 | E 볼드 그래픽 |
|---|---|---|---|---|---|
| 바탕 | 흰색 | 흰색 | 흰색 | 웜그레이 `#F4F2EE` | 흰색 + 귤색 블록 |
| 포인트 색 | 남색 `#002D74` | 청록 `#0B6E79` | 노랑 `#F2B544` · 남색 `#0C2A33` | 올리브 `#46533D` | 귤색 `#FF6B1A` · 검정 |
| 제목 글꼴 | Noto Serif KR 700 | Noto Sans KR 800 | Noto Sans KR 900 | Noto Sans KR 500 | Black Han Sans |
| CTA 버튼 | 검정 사각 | 청록 알약 | 노랑 알약 | 올리브 사각 | 흰 사각 · 검정 테두리 · 그림자 |
| 첫 화면 | 글 왼쪽, 사진 오른쪽 | 둥근 사진 액자 안에 글 | 사진을 화면 가득, 글은 사진 위 | 큰 제목 위, 넓은 사진 아래 | 귤색 블록, 기울인 사진 액자 |
| 한눈에 띠 | 선 사이 숫자 | 회색 타일 | 첫 화면에 걸친 흰 카드 | 가는 선 위 얇은 숫자 | 테두리 칸 |
| 대표 기사 | 사진 왼쪽, 글 오른쪽 | 둥근 회색 카드 | 화면 폭 남색 띠 | 넓은 사진 아래 두 칸 글 | 테두리 카드 |
| 기사 카드 | 세로 사진 + 명조 제목 | 둥근 사진 + 칩 | 사진 위에 제목 (휴대폰은 옆으로 넘김) | 번호 붙은 엇갈린 칸 | 테두리 카드 (휴대폰은 옆으로 넘김) |
| 매거진 커버형 표지 | 제목 가운데 위, 사진 아래 | 제목 위, 둥근 사진 | 사진을 화면 가득 | 두 칸 머리, 넓은 사진 | 귤색 블록, 사진 액자가 아래로 걸침 |
| 사진 모서리 | 없음 | 둥글게 | 둥글게 (표지 · 띠는 화면 가득) | 없음 | 없음, 검정 테두리 |

고르는 기준
- 가로로 찍은 좋은 사진이 많으면 C. 사진이 적거나 글이 중심이면 A 또는 D
- 정보 · 코스를 정리해 보여 주면 B
- 젊은 독자 · 액티비티 · 숏폼 광고와 이어지면 E
- 첫 화면은 광고와 같은 이야기여야 한다. 광고 이미지 분위기와 맞는 디자인을 고른다

## 3. 디자인 파일 쓰는 법 (Claude Code)

1. `/article` · `/submain` 때 `우리웹진.md`의 디자인 칸을 읽는다. 비어 있으면 C. A~E가 아니면 멈추고 알려준다
2. `public/css/style.css`가 `규칙/디자인/X.css`와 같은지 본다. 디자인 파일은 `/* 디자인 X`로 시작해 `/* ===== 팀 조정 =====`으로 시작하는 안내 주석(두 줄, `*/`로 끝난다)으로 끝난다. 그 `*/`까지 글자 하나까지 같아야 한다
3. 다르면 바꾼다
   - 지금 `style.css`에서 팀 조정 안내 주석의 `*/` 다음 줄부터 끝까지(있으면)를 떼어 둔다
   - `규칙/디자인/X.css`를 `public/css/style.css`로 복사한다
   - 떼어 둔 줄을 새 파일 맨 아래(안내 주석 `*/` 다음)에 다시 붙인다
   - "디자인을 C에서 E로 바꿨다"처럼 알려준다. 옮겨 붙인 줄이 있으면 그 줄을 보여 주고 새 디자인에서도 필요한지 묻는다 (디자인마다 기본 크기가 다르다)
4. html은 고치지 않는다. `규칙/submain.md` · `규칙/article.md`의 구성 · 클래스대로 만든 페이지는 어느 디자인이든 맞게 보인다
5. 다른 언어 페이지도 같은 `style.css`를 쓴다

## 4. 팀 조정 칸

- `style.css` 맨 아래 팀 조정 안내 주석(`/* ===== 팀 조정 =====` … `*/`) 다음 줄부터만 팀이 쓸 수 있다. 위쪽은 고치지 않는다
- 숫자로 말한 작은 조정만 적는다. 예: "휴대폰에서 첫 화면 제목을 36px에서 32px로" (디자인 C 기준. 휴대폰 첫 화면 제목은 A 32px · B 30px · C 36px · D 34px · E 46px). 학생이 지금 크기를 물으면 디자인 파일에서 찾아 알려준다
  ```css
  @media (max-width: 767px) { .hero-text h1 { font-size: 32px; } }
  ```
- 색 · 글꼴 · 배치를 바꾸지 않고, 한 페이지만 다르게 만들지 않는다. 그런 요청은 디자인 칸을 바꾸거나 강사와 상의하라고 알려준다
- 공통 틀(`.topbar` · `.wz-header` · `.wz-nav` · `.site-footer` · `.lang-switch`과 그 안의 요소)은 팀 조정 칸에서도 고치지 않는다

## 5. 지키는 것

- 글꼴은 디자인 파일 맨 위의 Google Fonts 한 줄에서 받는다 (CLAUDE.md 2번 1의 예외). 다른 글꼴 파일을 넣지 않는다
- 버튼 화살표(→ ←)와 소제목 번호(01, 02 …)는 디자인 파일이 붙인다. html 글자에 넣지 않는다
- Tailwind · Bootstrap 같은 CSS 프레임워크나 다른 css 파일을 연결하지 않는다. 참고한 사이트(템플릿 모음 등)가 그것으로 만들어졌어도 그 코드를 가져오지 않고, 디자인 칸(A~E)에서 가까운 것을 고른다. 숫자로 말한 작은 조정만 팀 조정 칸에 적는다(4번)
- 페이지에 `style="…"`로 색 · 크기를 적지 않는다 (팀 GTM 코드의 noscript 한 줄은 예외, `규칙/공통틀.md` 7번)
- 다섯 디자인은 한경닷컴이 서브메인과 6유형, PC · 휴대폰, 영어 페이지로 확인해 두었다. 디자인 파일 위쪽을 고치면 이 확인이 소용없어진다
