# 사진 정리 규칙 (Claude Code가 읽는다)

학생은 휴대폰 원본을 `콘텐츠/폴더/사진/`에 넣기만 한다 (파일 이름 자유). Claude Code가 사진을 보고 골라 자른다. `넣는법.txt`는 원본이 아니다.

## 1. 순서
1. 폴더의 원본을 모두 열어 본다 (무엇이 찍혔는지, 가로 · 세로, 크기, 글자 · 워터마크)
2. 쓰지 않을 사진을 뺀다 (3번)
3. 유형에 필요한 역할(4번)에 사진을 하나씩 정한다. 같은 원본을 다른 자리에 다르게 잘라 써도 된다. 서브메인에 나란히 놓이는 대표 사진은 콘텐츠마다 다른 장면으로
4. `tools/photo.py`로 자른다. 남길 부분의 가운데를 `--focus x,y`로 준다
5. `글.md`의 `## 사진` 칸에 한 줄씩 적는다: `- 역할: 만든 파일 | 사진 설명 | 원본 파일`
6. 학생에게 뺀 사진과 이유, 정한 대표 사진을 세 줄 이내로 알려준다

## 2. tools/photo.py

```
python3 tools/photo.py 원본 용도 주제 [이름중간] --focus x,y [--credit "출처 | 라이선스 | 원본 주소"]
```

Windows는 `python3` 대신 `python`으로 실행한다 (python.org에서 설치한 경우).

| 용도 | 비율 | 최대 크기 | 원본 최소 가로 | 용량 | 쓰는 곳 |
|---|---|---|---|---|---|
| `hero-16x9` | 16:9 | 1600×900 | 1200px | 500KB | 서브메인 히어로 PC |
| `hero-4x5` | 4:5 | 1080×1350 | 600px | 500KB | 서브메인 히어로 휴대폰 |
| `og` | 1200×630 | 1200×630 | 1200px | 300KB | 공유 미리보기 |
| `16x9` | 16:9 | 1600×900 | 500px | 300KB | 콘텐츠 대표 · 본문 · 넓은 사진 · 항목 · 장소 · 지도 |
| `4x5` | 4:5 | 1080×1350 | 300px | 300KB | 세로 본문 · 매거진 표지(휴대폰) · 카드 |
| `9x16` | 9:16 | 1080×1920 | 720px | 300KB | 풀페이지 장면(휴대폰) |

- Pillow가 없다는 오류가 나면 `python -m pip install pillow`(Mac은 `python3 -m pip install pillow`)를 한 번 하고 다시 실행한다. Python이 없으면 멈추고 따라하기.md 0번(설치)을 알려준다
- 파일 이름은 도구가 만든다: `주제-이름중간-비율.jpg`. 주제는 콘텐츠의 페이지 이름(예: `jeongbang-story`), 서브메인 첫 화면 사진은 웹진 주제(예: `jeongbang`). 대표 사진은 이름중간을 비운다
- 도구가 늘리지 않고, 용량을 맞추고, 휴대폰 회전을 바로잡고, 위치 정보(EXIF)를 지운다. `credits.txt`에도 한 줄을 적는다
- 원본이 '원본 최소 가로'보다 작으면 도구가 알려준다. 그 자리에는 다른 사진을 쓰거나 작은 자리(카드, 4:5)에 쓴다

## 3. 쓰지 않는 사진
- 다른 사람의 워터마크(©, 블로그 · 업체 이름)가 있는 사진. 잘라 내서 쓰지 않는다. 학생에게 알려준다
- 출처를 모르는 사진. `글.md`의 `## 출처`에 적힌 사진만 직접 찍지 않은 사진으로 쓴다 (`--credit`에 그 출처 · 라이선스 · 주소). 적히지 않은 사진은 직접 찍은 사진으로 보고 `--credit "직접 촬영(팀번호)"`
- 흔들리거나 너무 어두운 사진
- 학생이 찍은 사진에 휴대폰이 넣은 날짜 · 문구는 자를 때 남길 부분 밖으로 뺀다 (`--focus`). 도구가 알려주는 남긴 부분(상자)으로 확인한다. 뺄 수 없으면 그 자리에 쓰지 않는다

## 4. 유형별 역할

| 유형 | 역할 (`## 사진` 칸) |
|---|---|
| 블로그형 | 대표 (16x9) · 본문 2~4 (16x9 또는 4x5) |
| 매거진 커버형 | 대표(PC) (16x9) · 대표(모바일) (4x5, 같은 장면) · 본문 넓게 (16x9) · 본문 (4x5, 선택) |
| 리스트형 | 대표 (16x9) · 항목 (16x9, 항목마다) |
| 코스형 | 대표 (16x9) · 지도 (16x9) · 장소 (16x9, 장소마다) |
| 풀페이지형 | 대표(PC) (16x9) · 대표(모바일) (9x16) · 장면 (9x16과 16x9 한 쌍, `- 장면: a-9x16.jpg, a-16x9.jpg \| 설명 \| 원본`) |
| 카드뉴스형 | 대표 (16x9) · 카드 (4x5, 사진 카드마다) |
| 서브메인 첫 화면 (`우리웹진.md` 첫 화면 사진 칸) | 히어로(PC) (hero-16x9) · 히어로(모바일) (hero-4x5) · 공유 미리보기 (og). 대표 콘텐츠 폴더의 사진에서 먼저 고른다. 원본은 `폴더/사진/파일`로 적는다 |

## 5. 자르는 자리 (--focus)
- 주인공(폭포, 사람, 건물)이 잘리지 않게 가운데를 정한다
- **글자가 올라가는 사진**(히어로, 매거진 표지, 카드, 풀페이지 장면)은 주인공을 위쪽 2/3에 두고 아래쪽 1/3을 비운다
- 세로 원본에서 16:9를 자를 때는 가장 볼 만한 띠를 고른다. 같은 원본에서 두 장을 자르면 서로 다른 띠를 쓴다
- 히어로 PC와 휴대폰은 같은 장면이면 좋다. 같은 장면의 가로 · 세로 사진이 있으면 각각 쓴다

## 6. 사진 설명 (대체 텍스트)
- 사진에 **보이는 것만** 짧게 쓴다 (예: "폭포 아래 자갈밭과 물웅덩이"). 보이지 않는 사실(높이, 이름의 유래)은 쓰지 않는다
- 캡션으로도 쓰인다. 학생이 고칠 수 있게 `글.md`에 적어 둔다
