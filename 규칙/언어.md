# 다른 언어 규칙 (Claude Code가 읽는다)

`콘텐츠/우리웹진.md`의 **다른 언어** 칸에 언어 코드가 있을 때만 쓴다. 비어 있으면 한국어 페이지만 만든다.

## 0. 한눈에
- 한국어 페이지가 원본이다. 다른 언어 페이지는 같은 페이지를 그 언어로 옮긴 것이고 **주소를 따로 둔다**: `lxwebzine.hankyung.com/팀번호/en/…`
- 번역은 Claude Code가 하고, 옮긴 글은 **번역 파일(md)**에 적는다. 페이지는 번역 파일로 만든다. html을 직접 고치지 않는다 (CLAUDE.md 5번)
- 사진 · 영상 · 음악 · `css/style.css` · `js/site.js`는 한국어 페이지의 파일을 같이 쓴다. 디자인을 바꾸면 모든 언어가 함께 바뀐다
- 웹진메인(한경닷컴이 만드는 한 페이지)은 한국어만 있다. 다른 언어 페이지의 상단 바 링크도 웹진메인으로 간다

## 1. 다른 언어 칸

| 쓰는 값 | 언어 | 만드는 폴더 |
|---|---|---|
| `en` | 영어 | `public/en/` |
| `ja` | 일본어 | `public/ja/` |
| `zh` | 중국어(간체) | `public/zh/` |

- 여럿이면 ` · `로 나눈다 (예: `en · ja`). 언어 전환은 한국어 다음에 적힌 순서대로 놓인다
- 표에 없는 언어는 먼저 강사와 상의한다 (6번 화면 글자 표와 `js/site.js`에 그 언어를 더해야 한다)

## 2. 파일과 주소
```
콘텐츠/우리웹진.md           → 콘텐츠/우리웹진.en.md       (Claude Code가 만든다)
콘텐츠/폴더이름/글.md         → 콘텐츠/폴더이름/글.en.md
public/index.html             → public/en/index.html
public/articles/페이지이름.html → public/en/articles/페이지이름.html
```
- 페이지 이름 · 사진 파일 이름은 한국어 페이지와 같다
- 경로는 한 단계 더 깊다: 다른 언어 서브메인은 `../images/` · `../css/style.css` · `../js/site.js`, 상세페이지는 `../../images/` · `../../media/` · `../../css/style.css`. 같은 언어 안의 링크(`./articles/…`, `../index.html`, `#cat-1`)는 한국어 페이지와 같게 쓴다
- `site.json`은 한국어만 만든다 (웹진메인이 읽는다)

## 3. 번역 파일
원문(ko)과 번역(en)을 짝으로 적는다. 학생이 번역을 확인하고 고치는 곳이다.
```
- ko: 바다로 곧장 떨어지는 폭포, 정방폭포
- en: Jeongbang Waterfall, Falling Straight into the Sea
```
- **옮기는 것**: 한글이 있는 글자 덩어리 전부
  - `우리웹진.md`: 웹진 이름 · 한 줄 소개 · 글쓴이 · 메뉴 카테고리(하나씩) · CTA 문구 · 권하는 문장 · 받는 것 · 광고 문구 · 리드 한 줄 · 배지 · 한눈에 띠(양쪽) · 첫 화면 사진 설명
  - `글.md`: 제목 · 한 줄 요약 · 본문(문단, 소제목, `>` 큰 문장, `- 항목: 값`의 항목과 값, `→` 이동 줄을 하나씩) · 사실 정보(항목과 값. 마지막 `확인` 줄은 값만) · 사진 설명 · 영상 · 음악 설명 · 출처
  - 여러 줄로 쓴 문단은 한 줄로 이어 붙인 것(줄 사이에 빈칸 하나)이 `ko:` 한 줄이다
- **옮기지 않는 것**: 한글이 없는 것(숫자 · 영문 · 파일 이름), 폴더 이름, 유형, 날짜, 페이지 이름, `[사진: …]` · `[영상: …]` 줄, 카드뉴스형의 `### 카드`, 리스트형 번호(`1.`)와 코스형 시각(`09:00`)
- 짝은 md에 나오는 순서대로 적고 묶음 제목을 단다. 글.md는 `## 제목 · 한 줄 요약` · `## 본문` · `## 사실 정보` · `## 사진 · 영상 · 음악 설명`, 우리웹진.md는 `## 웹진` · `## 독자에게 권할 행동` · `## 첫 화면 · 한눈에 띠` · `## 첫 화면 사진 설명`. 같은 원문은 한 번만 적는다
- 맨 위 안내 주석은 지우지 않는다. 일본어는 `- ja:`, 중국어는 `- zh:` 줄을 쓴다 (파일 이름도 `글.ja.md`)

## 4. 옮기는 때와 맞추는 법
- `/article 폴더이름`: 그 폴더의 `글.en.md`와 `우리웹진.en.md`를 맞춘 뒤 한국어 · 다른 언어 상세페이지를 함께 만든다
- `/submain`: `우리웹진.en.md`와 모든 콘텐츠의 `글.en.md`를 맞춘 뒤 모든 언어의 서브메인 · 상세페이지를 맞춘다
- 번역 파일이 이미 있으면 이렇게 맞춘다
  1. 원문(`ko:`)이 지금 md와 글자 하나까지 같은 짝은 **그대로 둔다** (학생이 고친 번역을 지킨다)
  2. md에 새로 생기거나 바뀐 덩어리만 새로 옮겨 짝을 더한다
  3. md에 없는 원문의 짝은 지운다
  4. 새로 옮긴 줄 수를 알려준다 (예: "글.en.md 새로 옮긴 줄 2개")
- 학생이 `ko:` 줄을 고쳤으면 원문과 맞지 않으니 새로 옮긴다. 그래서 `ko:` 줄은 고치지 말라고 안내한다
- 학생이 "영어 번역을 다시 해줘"라고 하면 그 파일의 모든 짝을 새로 옮기고, 고친 줄을 보여 준다

## 5. 번역 원칙
- 뜻을 바꾸지 않는다. 원문에 없는 설명 · 사실 · 꾸밈말을 더하지 않는다 (CLAUDE.md 2번 6)
- 그 언어를 쓰는 여행자가 읽기 쉬운 문장으로 쓴다. 한국어 어순을 그대로 따르지 않는다
- 고유명사는 국어의 로마자 표기법을 따르고 종류를 붙인다 (정방폭포 → Jeongbang Waterfall, 서귀포 → Seogwipo). 웹진 안에서 같은 이름은 같게 쓴다
- 주소는 영문 도로명 주소, 돈은 `KRW 2,000`, 전화번호는 그대로
- 버튼 글자(CTA 문구)는 짧게 옮긴다 (휴대폰에서 한 줄). 메뉴 카테고리도 한두 단어로 짧게 옮기고 (예: 이야기 → Story), 서로 달라야 한다. 영어는 한국어보다 길어 휴대폰에서 메뉴가 두 줄이 되기 쉽다
- 한자 · 원어 병기(徐市過之)는 그대로 둔다
- 번역은 발행 전에 팀원이 번역 파일을 읽고 확인한다. 어색한 줄은 `en:` 줄을 고치고 `/article`

## 6. 화면 글자 표

## 7. 페이지
- `<html lang="en">`. 구조 · 클래스 · `data-track` · `data-excerpt`는 한국어 페이지와 같다
- `canonical` · `og:url`은 그 언어 주소 (`https://lxwebzine.hankyung.com/팀번호/en/articles/페이지이름.html`, 서브메인은 `https://lxwebzine.hankyung.com/팀번호/en/`). `og:image`는 한국어 페이지와 같은 사진 주소
- 모든 언어 페이지의 `<head>`에, canonical 다음 줄에 같은 페이지의 모든 언어 주소를 적는다 (검색엔진이 언어별 페이지를 알게 한다)
```html
<link rel="alternate" hreflang="ko" href="https://lxwebzine.hankyung.com/팀번호/articles/페이지이름.html">
<link rel="alternate" hreflang="en" href="https://lxwebzine.hankyung.com/팀번호/en/articles/페이지이름.html">
<link rel="alternate" hreflang="x-default" href="https://lxwebzine.hankyung.com/팀번호/articles/페이지이름.html">
```
- 공통 틀의 상단 바에 언어 전환을 넣는다 (규칙/공통틀.md 6번)
- 날짜는 한국어 페이지와 같게 쓴다 (2026.10.07)

## 8. 언어를 빼거나 더할 때
- 다른 언어 칸에서 지우고 `/submain` → `public/en/` 폴더를 지우고, 모든 페이지에서 언어 전환 · hreflang 줄을 뺀다. 번역 파일(`*.en.md`)은 지우지 않는다 (다시 켜면 고친 번역 그대로 쓴다)
- 언어를 더하고 `/submain` → 모든 콘텐츠를 옮겨 번역 파일을 만들고 모든 페이지에 전환을 넣는다

## 9. 검수 (/check에 더한다)
- 다른 언어 칸 = `public/`의 언어 폴더
- 언어마다 같은 페이지가 있다
- `<html lang>`이 언어 폴더와 같다
- 언어 전환이 같은 페이지의 다른 언어로 가고, hreflang에 모든 언어 + x-default가 있다
- 다른 언어 페이지에 한글이 없다 (언어 전환의 `한국어`만 예외). 화면 글자 · alt · aria-label · title · description 모두 본다
- 공통 틀은 같은 언어끼리 글자 하나까지 같다 (언어 전환 링크는 페이지마다 다르니 빼고 비교)
- 다른 언어 메뉴 = 번역 파일의 메뉴 카테고리 번역, 적힌 순서대로
