## 채운 칸이 나오는 곳

| 칸 | 나오는 곳 |
|---|---|
| 팀 번호 | 실제 주소 `lxwebzine.hankyung.com/팀번호/`. 한경닷컴이 알려준 번호 (예: team3) |
| 웹진 이름 · 한 줄 소개 · 메뉴 카테고리 | 모든 페이지의 헤더와 메뉴 (PC · 휴대폰 같음) |
| 디자인 | 모든 페이지의 모양 (색 · 글꼴 · 배치). `public/css/style.css`만 바뀌고 글 · 사진은 그대로다 |
| 글쓴이 | 모든 콘텐츠의 글쓴이 |
| CTA 문구 · 권하는 문장 · 받는 것 | 첫 화면 버튼, 모든 콘텐츠 끝의 버튼, 서브메인 구독 띠 |
| 광고 문구 · 리드 한 줄 · 배지 | 서브메인 첫 화면 |
| 대표 콘텐츠 | 서브메인의 큰 카드 (콘텐츠 폴더 이름). 첫 화면 사진도 이 폴더의 사진에서 먼저 고른다. 비우면 가장 최근 콘텐츠 |
| 팀 GTM 아이디 | 모든 페이지의 측정 코드 (화면에는 보이지 않는다. 규칙/공통틀.md 7번) |
| 핵심 독자 · 주제 | 페이지에는 안 나온다. Claude Code가 첫 화면 문구 · 요약을 제안할 때 기준으로 쓴다 |
| 다른 언어 | `en`이면 영어 페이지를 `lxwebzine.hankyung.com/팀번호/en/`에 따로 만든다. 모든 페이지 상단 바에 `한국어 · English` 전환 |

서브메인 카드는 콘텐츠 폴더마다 하나씩, 글.md의 날짜가 최신인 것부터 놓인다.
